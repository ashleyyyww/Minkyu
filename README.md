# Minkyu

Play custom Muse Dash songs on Android. No root needed.

## Usage

1. Download `Minkyu.apk` from [Releases](https://github.com/ashleyyyww/Minkyu/releases).
2. Open Minkyu and set it up with your Muse Dash APK and OBB.
3. Install the modified game and import your `.mdm` songs.
4. Tap Play and select Custom Albums in Muse Dash.

Close Muse Dash before adding or removing songs.

You can also find **Mod Settings** under Options in Muse Dash. This is where you can enable or disable Info+, Scoreboard Characters, Rank Preview, SelectiveEffects, custom chart dialogue and Cinema videos.

## Requirements

- Android 7.0+ (ARM64)
- Muse Dash 6.7.0 (build 626)
- A standalone Muse Dash APK and matching OBB

Split APKs and games with an existing mod loader aren't supported.

## Notes

- Back up your game saves before setup. You may need to uninstall the original game.
- Don't uninstall Minkyu when updating. Your imported songs and game-signing key are stored in the app.
- MDMC leaderboards are available for custom charts, but uploading scores isn't supported yet.
- Google and Facebook login aren't working. You can use Pero login under Mod Settings → Account.
- Supports up to 256 songs.

If you run into any crashes or bugs, DM me on Discord: `minkyu._.`
